# Recommended Books for DSA & Competitive Programming

## 1. Comprehensive Foundations
- **Introduction to Algorithms (CLRS)** — *Cormen, Leiserson, Rivest, Stein*
  - *Best for:* Rigorous mathematical proofs, asymptotic recurrence, advanced graph algorithms.
- **Algorithm Design** — *Kleinberg & Tardos*
  - *Best for:* Developing greedy choice proofs and dynamic programming formulations.

## 2. Practical Implementation & Interviews
- **Cracking the Coding Interview (CTCI)** — *Gayle Laakmann McDowell*
  - *Best for:* Classic interview problem breakdowns and system design basics.
- **Elements of Programming Interviews (EPI)** — *Aziz, Lee, Prakash*
  - *Best for:* Rigorous problem sets categorized by data structure with production-quality code.

## 3. Competitive Programming
- **Competitive Programmer’s Handbook** — *Antti Laaksonen* (Free PDF available online)
  - *Best for:* Fast, practical guide to algorithms, number theory, and bit manipulation.
- **Guide to Competitive Programming** — *Antti Laaksonen*
