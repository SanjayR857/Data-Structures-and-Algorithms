## 📁 File Types & When to Use Them

- **`.md`**: Permanent theory, conceptual explanations, complexity analysis, and problem write-ups.
- **`.ipynb`**: Interactive learning, visual step-by-step dry runs, and sandbox experiments.
- **`.py` / `.cpp` / `.java`**: Clean, modular, production-grade algorithm implementations.
- **`.csv`**: Tabular tracking for progress, problem indices, and spaced repetition schedules.

---

## 🏷️ Naming & Structure Conventions

- **Folders**: Numbered prefixes for learning order (`01-Arrays/`, `02-Sorting/`)
- **Notes**: Hyphenated lowercase markdown (`complexity-analysis.md`, `two-sum.md`)
- **Python**: Snake case (`merge_sort.py`)
- **C++**: Snake case (`merge_sort.cpp`, standard: C++17)
- **Java**: PascalCase (`MergeSort.java`, standard: JDK 17+)
- **Dates**: ISO 8601 format (`YYYY-MM-DD`)
