## 4-Step Interview Communication Script
1. **Clarify Constraints (5 mins):** Ask about empty inputs, range of values, duplicates, time/space targets.
2. **Brainstorm & Discuss Trade-offs (5-10 mins):** Propose brute force first, then identify the bottleneck to pitch the optimal approach. Confirm the interviewer agrees before coding.
3. **Write Clean Code (15-20 mins):** Modular naming, clean indentation, thinking aloud as you type.
4. **Dry Run with Test Cases (5-10 mins):** Manually trace a normal case and an edge case before declaring completion.
