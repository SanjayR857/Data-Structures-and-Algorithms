# Topic Checklist

Use this checklist to track your multi-dimensional progress for each topic:
- **Theory**: Conceptual understanding documented in `01-Concepts.md`.
- **Analysis**: Time and space bounds documented in `03-Complexity-Analysis.md`.
- **Implementations**: Coded in Python, C++, and Java under `implementations/`.
- **Practice**: Solved standard Easy, Medium, and Hard problem sets.

---

## 1. Programming Fundamentals & Analysis
- [ ] Asymptotic Notations ($O, \Omega, \Theta$)
- [ ] Recurrence Relations & Master Theorem
- [ ] Amortized Analysis (e.g., dynamic array doubling)
- [ ] Recursion & Backtracking basics
- [ ] Bit Manipulation (AND, OR, XOR, shifts, masks)
- [ ] Math: Prime Sieve, GCD/LCM, Modular Arithmetic

## 2. Linear Data Structures
- [ ] Arrays (Static vs Dynamic, prefix sums, memory layout)
- [ ] Strings (Immutability, pattern matching, two pointers)
- [ ] Singly & Doubly Linked Lists (reversal, cycles, dummy heads)
- [ ] Stacks & Monotonic Stacks
- [ ] Queues, Deques & Circular Buffers

## 3. Non-Linear Data Structures
- [ ] Hash Tables & Hash Sets (collision resolution, open addressing)
- [ ] Binary Trees & Traversals (DFS, BFS)
- [ ] Binary Search Trees (validation, balance, deletions)
- [ ] Heaps & Priority Queues (min-heap, max-heap, heapify)
- [ ] Tries (Prefix Trees, auto-complete, XOR tries)
- [ ] Disjoint Set Union / Union-Find (Path compression, rank)

## 4. Algorithms
- [ ] Searching (Linear, Binary Search, Search on Answer)
- [ ] Sorting (Merge Sort, Quick Sort, Counting/Radix Sort)

- [ ] Advanced (Segment Tree, Fenwick Tree)
