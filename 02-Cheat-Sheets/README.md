## Guiding Principles for Cheat Sheets
1. **Never copy full chapter notes:** Cheat sheets are for quick scanning during the final 30 minutes before an interview.
2. **Prioritize syntax gotchas:** e.g., how to do a Max-Heap in Python (`-val`), C++ (`priority_queue<int>`), or Java (`Collections.reverseOrder()`).
3. **Include the "Trigger" phrase:** What problem statement wording tells you to use this structure or template?
