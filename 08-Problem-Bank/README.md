## Canonical Problem Rule
If a problem appears across multiple platforms (e.g., LeetCode 1 and CSES Distinct Numbers), keep **one single canonical explanation** here in `08-Problem-Bank/` and link to it from interview lists or competitive programming sheets. **Never duplicate markdown solution files.**
