# Topic: Arrays (Static and Dynamic)

Arrays are the most fundamental contiguous linear data structure in computer science.

## Directory Layout & Purpose

```text
01-Arrays/

├── 01-Concepts.md                 # Definition, memory layout, cache locality, trade-offs

├── 03-Complexity-Analysis.md      # Time & space complexity table across operations
├── learning/                      # Interactive Jupyter notebooks for experimentation
│   ├── README.md                  # Notebook guides & topics (basics, operations, visualization)
│   ├── arrays-basics.ipynb        # Interactive introduction and index access
```
